# Design Tokens

Every value below is wired into the `@theme` block in `src/index.css`, which is what makes
`bg-teal-500`, `text-ink-muted` and `rounded-2xl` resolve. This page renders the committed values
so they can be seen rather than read as hex codes.

The brand language is "soft-modern": teal primary, warm neutral surfaces, generous radii, Nunito for
headings. It deliberately avoids the cold clinical look of most health apps — a parent opens this at
3am, not a clinician at a workstation.

### Which shade is a text color

Only the light and decorative shades are pinned to the reference. The darker `600`/`700` steps of
amber, rose and violet are **not** overridden — they fall through to stock Tailwind, which is dark
enough to stay readable.

That distinction is load-bearing: the original design reference uses shades like `amber-400` and
`amber-500` as text on light backgrounds, and those fail WCAG AA. **Status text uses the `600`/`700`
step; the `400`/`500` steps are for fills, borders and decoration.**

### Where the tokens deviate from the Figma reference

Four values are deliberately not the reference's. Each was below a WCAG threshold, each was caught
by this Storybook's own axe suite, and each is commented at the point of definition in
`src/index.css`:

| Token | Reference | Shipped | Why |
| --- | --- | --- | --- |
| `--primary` | `#2A9D8F` (teal-500) | `#186560` (teal-700) | 3.3:1 — predates this Storybook |
| `--color-ink-faint` | `#9AA5B4` | `#5F6E81` | 2.49:1 on white, used as 10–12px copy in 25 places |
| `--destructive` | `oklch(0.577 …)` | `oklch(0.529 …)` | 3.98:1 as text on its own 10% tint |
| `--muted-foreground` | `oklch(0.556 …)` | `oklch(0.532 …)` | 4.34:1 on `--muted` |

Darkening `ink-faint` compresses the bottom of the ink scale — `ink-muted` and `ink-faint` now read
closer together than the reference intended. That is the cost of the token being legible at all, and
it is a trade worth naming rather than hiding.

The `ink` scale and `surface` are fixed hex values, so they do not invert on their own. They are
redefined under `.dark` with ratios measured against `--card`, the darkest surface they land on:
`ink` 16.4:1, `ink-muted` 8.6:1, `ink-faint` 5.9:1.

There are **no** standing exceptions in the a11y suite: every story is checked with
`color-contrast` enabled, in both themes.

## Per-feature color map

Not one global accent: each concept is colored consistently across every screen it appears on, so a
parent learns the mapping once.

| Concept | Color |
| --- | --- |
| Vaccine `APPLIED` / Appointment `COMPLETED` | teal |
| Vaccine `PENDING` | amber |
| Vaccine `DELAYED` | rose |
| Vaccine `GUIDANCE` | sky (stock Tailwind — see below) |
| Appointment `SCHEDULED` | violet |
| Milestone `MOTOR` | teal |
| Milestone `LANGUAGE` | violet |
| Milestone `SOCIAL` | amber |
| Milestone `COGNITIVE` | rose |
| Cancelled / `OTHER` | neutral slate |

`sky` is the one accent outside the brand palette: it marks catalogue *guidance* rather than a dose a
child owes, and reusing teal or amber for that would have collided with "done" and "pending". It is
not pinned in `@theme`, so it resolves to stock Tailwind. Its 700/800/900 steps are the ones in use
(5.6:1 to 9.1:1 on the tinted grounds) — the same 600-step trap the other families have applies here.

## Typography

Two self-hosted variable fonts, loaded through `@fontsource-variable` rather than a CDN — no
third-party request on first paint, and no layout shift when it fails.

## Radius

Base `--radius` is `0.625rem` (10px); the rest of the scale derives from it. `--radius-2xl` lands on
18px exactly, which is the card radius the design reference uses.
